# Кейс №5. Аналитический обзор

Для анализа выбран кейс №3 - Django-приложение приветствия.

Обзор в итоговом отчете выполнен по девяти критериям: функциональность, производительность, удобство использования, безопасность, масштабируемость, сопровождаемость, переносимость, качество кода и тестирование.
