# Кейс 2. Счетчик

Счетчик написан на HTML, CSS и JavaScript.

- диапазон: от -10 до 10;
- положительное значение - желтый фон;
- отрицательное - зеленый;
- ноль - красный;
- на 10 блокируется `+`;
- на -10 блокируется `-`;
- на границах выводится сообщение о достижении экстремального значения.

## Запуск

Открыть `index.html` в браузере.

## Тесты

```bash
node --test test_counter.js test_dom.js
```
