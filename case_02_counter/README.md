# Кейс №2. Интерактивный счетчик

Простое браузерное приложение на HTML, CSS и vanilla JavaScript.

## Возможности

- увеличение и уменьшение значения кнопками `+` и `-`;
- диапазон от -10 до 10;
- желтый фон результата при положительном значении;
- зеленый фон при отрицательном значении;
- красный фон при нуле;
- автоматическое отключение кнопки `+` при 10 и кнопки `-` при -10;
- сообщение о достижении экстремального значения;
- градиентный фон страницы и кнопок, центрирование интерфейса.

## Запуск

Откройте файл `index.html` в современном браузере.
