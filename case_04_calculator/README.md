# Кейс 4. Калькулятор

Калькулятор написан на HTML, CSS и JavaScript. Поддерживаются операции:

- сумма;
- разность;
- произведение;
- деление.

Можно вводить целые, дробные и отрицательные числа. Для дробной части принимаются точка и запятая. Пустые значения, текст вместо числа и деление на ноль выводятся как ошибки.

## Запуск

Открыть `index.html` в браузере.

## Тесты

```bash
node --test test_calculator.js test_dom.js
node --check script.js
```
