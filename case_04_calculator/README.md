# Кейс №4. Интерактивный калькулятор

Простое браузерное приложение на HTML, CSS и vanilla JavaScript.

Поддерживаются операции "Сумма", "Разность", "Произведение" и "Деление", дробные и отрицательные числа, обработка ошибочного ввода и деления на ноль.

Запуск: откройте `index.html` в современном браузере.
