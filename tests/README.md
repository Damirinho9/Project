# Тесты

Запуск из корня репозитория:

```bash
python tests/run_all_tests.py
```

Скрипт выполняет:

- 10 тестов кейса 1;
- 7 тестов логики и 2 DOM-теста счетчика;
- статическую проверку Django-проекта;
- `manage.py check`, проверку миграций и Django-тесты, если Django установлен;
- 10 тестов логики и 3 DOM-теста калькулятора.

Результаты контрольного прогона записаны в `TEST_RESULTS.md`.
