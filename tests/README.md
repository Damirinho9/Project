# Проверка проектов

Общий запуск доступных тестов выполняется из корня репозитория:

```bash
python tests/run_all_tests.py
```

Скрипт запускает:

- 10 Python-тестов кейса №1;
- 7 модульных и 2 DOM-теста счетчика;
- статическую проверку Django-проекта;
- при установленном Django - `manage.py check`, проверку миграций и Django-тесты;
- 10 модульных и 3 DOM-теста калькулятора.

Фактические результаты контрольного прогона приведены в `TEST_RESULTS.md`.
