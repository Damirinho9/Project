# Кейс 1. Дата рождения

Программа запрашивает день, месяц и год рождения и выводит:

- день недели;
- признак високосного года;
- текущий возраст;
- дату в формате `дд мм гггг`, набранную символами `*`.

Несуществующие даты и даты из будущего отклоняются.

## Запуск

```bash
python birthday.py
```

## Тесты

```bash
python -m unittest -v test_birthday.py
```

Сторонние библиотеки не используются.
